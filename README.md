# Fei Kang · 康飞

Personal research homepage: **https://kf953741.github.io/**

Buildless HTML, CSS, and JavaScript. Published with GitHub Pages from `main` at `/`.

## Local preview

Run `python3 -m http.server 8765 --bind 127.0.0.1` from this directory, then open `http://127.0.0.1:8765`.

## Editing

- `index.html`: English content, research entries, links, and metadata.
- `script.js`: Chinese translations, language selection, research filters, mobile navigation, and video controls.
- `styles.css`: responsive layout and visual design.
- `assets/`: local project imagery and an optimized official demonstration clip.

English content remains readable without JavaScript. `?lang=zh` opens the Chinese version. Language preference is stored locally in the browser.

## Source material

Project images and demonstrations are from the official [Riemann-1.0](https://riemann-dynamics.github.io/Riemann-1.0-Website/), [Matrix-Game 3.5](https://matrix-game-v3-5.github.io/), [Matrix-Game 3.0](https://matrix-game-v3.github.io/), and [Matrix-3D](https://matrix-3d.github.io/) project pages. The 15-second Matrix-Game 3.0 video is re-encoded for web playback; its poster is a frame extracted from that video. Model results are project-reported metrics, with relevant papers linked alongside them.

Personal contribution statements reflect the author's supplied descriptions. No analytics, account system, or third-party runtime is required.
